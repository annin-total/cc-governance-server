# 画面のスタイル仕様

**画面の見た目に関する決まりは、この文書に閉じる。**他の文書にスタイルの話を書かない。

実体は `static/app.css` と `templates/_macros.html` にある。
**ここには、コードを読んでも分からないことだけを書く。**値の一覧や画面ごとの構成は書かない。

## 原則

**見るのは管理者だけである。装飾を増やさない。**
手間は、**どの数字がどの母集団の、どの期間のものかを取り違えさせないこと**に使う。

## 表

- `<div class="tbl">` で包む。**`<table>` と `<tr>` に属性を足さない**
  - ビューのテストが正規表現で HTML を照合しており、`<table data-testid="...">` と
    裸の `<tr>` を前提にしている。属性を足すと行数の検査が 0 件になって全滅する
  - スタイルは `table` / `th` / `td` の要素セレクタで当てる。表に class は要らない
- 数値列は `td.num`、日付列は `td.date`。**`nowrap` はこの 2 つにだけ当てる**
  - `user_email` や `command_name` は長い。全セルに当てると横スクロールが常態化する
- **枠と表は内容幅にする。**列が 2〜3 しかない表を画面幅いっぱいに広げると、
  値と値の間が空いて対応が読み取れなくなる
- 0 件のときは `m.empty` に差し替える。
  **ただし `data-testid` で行数を検査されている表は、0 件でも表のまま出す**

## 数字

- **生の値を画面に出さない。**`day` は JST 基準の epoch 日であり、そのままでは読めない。
  整形は `formatting.py` のフィルタに寄せ、テンプレートで組み立てない
- **率は `75.0% (3/4)` の形で分子・分母を併記する。**
  この画面の率は分母が 4 種類ある（イベント数／利用者数／イベントを送った利用者数／
  コストが立つ利用者数）。％だけでは読み分けられない
- **節の見出し直下に `m.chips` で期間と母集団を書く。**
  7 日・14 日・30 日・全期間が 1 画面に混在する。断りがなければ同じ期間だと読まれる
- **仕様上の欠落は `.note` で明記する。**相対日 0 の除外と、度数 0 のビンを出さないことは
  仕様であり、書かなければ障害に見える
- 同じ値を 2 箇所に出さない。率をタイルで見せる節では、タイルの外にもう一度出さない

## 色と余白

- **直値を書かない。**`:root` のトークンを使う
- **`--muted` を明るくしない。**`#5f6c73` で白地に 5.42:1。
  先行実装の `#6f7c83` は 4.30:1 で WCAG AA（4.5:1）に届かない
- `.pill` の修飾子は `.ok` `.warn` `.ng` `.neutral` の **4 つだけ**。状態名を増やさない。
  どの状態をどの色に写すかはテンプレート側で決める
- **`.note` と `.pill` の文字を 12px より小さくしない。**
  `--warn` を `--warn-soft` 上で使うと 4.56:1 で、AA をかろうじて満たす水準にある

## 入れないもの

ダークモード、印刷用スタイル、グラフ描画、CSS フレームワーク、ビルド工程、アニメーション。
**管理者だけが見る画面であり、いずれも費用に見合わない。**
トークン方式なので、必要になったときに足せる。

## 変えるとき

- 新しいクラスを足す前に `static/app.css` の語彙を見る。同じ役割のものが既にある
- **表示の形を変えたら、その文字列をテストが検査していないか確かめる。**
  検査していたら、同じ強さの検査に書き直し、**値を別の変数に差し替えて落ちることまで確認する**
- 画面を足したら `tests/test_views_completeness.py` が
  「集計したのに画面に出していない変数」を落とす。この検査を迂回しない
- **サーバを再起動せずに目視しない。**本番モードはテンプレートをキャッシュするため、
  古い画面を見て「直った」と誤認する

## 未検証

- コントラスト比は WCAG 2.1 の式による計算値であり、実機の表示では測っていない
- `sticky` な見出しセルを、縦に長い実データで確かめていない
- 画面幅を狭めたときの折り返しは確かめていない。想定は広い画面である
